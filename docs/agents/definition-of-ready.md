# Definition of Ready

An issue is **ready** when it can be picked up — by a human or an AI agent — without needing further clarification from the reporter.

## When to use this

During triage (see [triage-labels.md](triage-labels.md)), post the checklist below as a comment at the bottom of the issue. An issue only moves to `ready-for-agent` or `ready-for-human` once every applicable box is checked.

## Checklist

```markdown
## ✅ Definition of Ready

- [ ] Problem or goal is clearly described
- [ ] Acceptance criteria are defined and testable
- [ ] Affected component(s) or package(s) identified
- [ ] Scope is well-defined (not open-ended)
- [ ] No open questions blocking implementation
- [ ] Design reference attached, or no design review needed
- [ ] Breaking change impact assessed, if applicable
- [ ] Correct labels applied
```
