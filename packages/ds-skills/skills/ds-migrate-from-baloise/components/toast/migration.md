# toast

Migrate every `bal-toast` usage to `ds-toast`. Init has already added the `@helvetia-design/*` packages. This task rewrites usages only.

The legacy folder has no child elements. Rewrite `bal-toast` only. Leave slotted content in place. `bal-close` is drawn inside the legacy toast and is not a consumer tag. `bal-toaster` and `BalToaster` are not this component and stay unchanged.

## 1. Scan

`<project-root>` is the consumer project root that contains the app lockfile. When the skill is invoked from that root, use the current directory.

```bash
node <this-skill-directory>/scripts/scan-bal-toast.mjs <project-root>
```

The script prints one JSON object. `total` is the number of findings. `files` groups them by path. Each finding has `line` and `snippet`.

Show that list to the user grouped by file (path, line, snippet) and end with the total count.

Done when the user has seen every finding and the total. If `total` is 0, say there are no `bal-toast` usages to migrate and stop.

### Tags and imports

- **HTML**: `<bal-toast>` becomes `<ds-toast>`, including the closing tag.
- **Angular**: `<bal-toast>` becomes `<ds-toast>` in `.html` templates and in inline `template:` strings, including the closing tag. When a file imports `BalToast` from `@baloise/ds-angular`, move only `BalToast` to `import { DsToast } from '@helvetia-design/angular'` and leave the other symbols on the `@baloise` import.
- **React**: `<BalToast>` becomes `<DsToast>` and `</BalToast>` becomes `</DsToast>`. Import `DsToast` from `@helvetia-design/react`. When the existing `@baloise/ds-react` import also binds other symbols, move only `BalToast` to `import { DsToast } from '@helvetia-design/react'` and leave the other symbols on the `@baloise` import. The generated `DsToast` wrapper is deprecated. JSX still rewrites to `DsToast`. Say in the summary that presenting a toast from code should use `useToast` from `@helvetia-design/react`. Do not rewrite JSX into that hook.

### Controller and service

`bal-toast.controller.ts` exports `balToastController`, `BalToastController`, and `BalToastOptions`. Angular exports `BalToastService`. `scripts/scan-bal-toast.mjs` lists those identifiers even when the file has no `<bal-toast>` tag. Detect does not. It counts `bal-toast` and `BalToast` as `toast`. `BalToastController` is a different slug, and `balToastController` is not a tag, so a controller-only project is not suggested. Choose toast from Manual, then rewrite every listed file.
