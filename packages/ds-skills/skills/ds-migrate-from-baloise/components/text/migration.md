# text

Migrate every `bal-text` usage to `ds-text`. Init has already added the `@helvetia-design/*` packages. This task rewrites usages only.

The legacy folder has no child elements. Rewrite `bal-text` only. Leave any child content in place. `bal-textarea` and `BalTextarea` are a different component and stay unchanged.

## 1. Scan

`<project-root>` is the consumer project root that contains the app lockfile. When the skill is invoked from that root, use the current directory.

```bash
node <this-skill-directory>/scripts/scan-bal-text.mjs <project-root>
```

The script prints one JSON object. `total` is the number of findings. `files` groups them by path. Each finding has `line` and `snippet`.

Show that list to the user grouped by file (path, line, snippet) and end with the total count.

Done when the user has seen every finding and the total. If `total` is 0, say there are no `bal-text` usages to migrate and stop.

## 2. Confirm

Ask for one yes/no: rewrite every listed usage?

On no, stop with the files unchanged.

On yes, continue. Editing starts only after that answer.

Done when the user has answered.

### Tags and imports

- **HTML**: `<bal-text>` becomes `<ds-text>`, including the closing tag.
- **Angular**: `<bal-text>` becomes `<ds-text>` in `.html` templates and in inline `template:` strings, including the closing tag. When a file imports `BalText` from `@baloise/ds-angular`, move only `BalText` to `import { DsText } from '@helvetia-design/angular'` and leave the other symbols on the `@baloise` import.
- **React**: `<BalText>` becomes `<DsText>` and `</BalText>` becomes `</DsText>`. Import `DsText` from `@helvetia-design/react`. When the existing `@baloise/ds-react` import also binds other symbols, move only `BalText` to `import { DsText } from '@helvetia-design/react'` and leave the other symbols on the `@baloise` import.

### Events

There are no event changes. Neither `bal-text` nor `ds-text` emits a custom event. Leave existing event bindings unchanged.
