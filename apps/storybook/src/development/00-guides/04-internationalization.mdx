## Regions & Languages

The following **regions** and **languages** are supported:

<Markdown>
  {`
| Region | Languages      | Interface               |
| ------ | -------------- | ----------------------- |
| CH     | de, fr, it, en | \`DsSwissLanguage\`       |
| BE     | fr, nl         | \`DsBelgiumLanguage\`     |
| DE     | de             | \`DsGermanLanguage\`      |
| LU     | fr, de, en     | \`DsLuxembourgLanguage\`  |
| AT     | de             | \`DsAustriaLanguage\`     |
| ES     | es             | \`DsSpainLanguage\`       |
| IT     | it             | \`DsItalyLanguage\`       |
| NL     | nl             | \`DsNetherlandsLanguage\` |
| FR     | fr             | \`DsFranceLanguage\`      |
`}
</Markdown>

Additionally an **allowedLanguages** should be passed to the configuration.
It is used to display the language selection for the user.

## Initialize

The initialize of the Design System config defines the default values.

<AngularFramework>

${' '}providers: [

${' '}${' '}${' '}defaults: {
${' '}${' '}${' '}${' '}region: 'DE',
${' '}${' '}${' '}${' '}language: 'de',
${' '}${' '}${' '}${' '}allowedLanguages: ['de', 'fr', 'it', 'en'],
${' '}${' '}${' '}},
${' '}${' '}}),
${' '}],
}
`} />

</AngularFramework>

<HTMLFramework>

<Code language="ts" code={`
import { initialize } from '@helvetia-design/core'

<ReactFramework>

}

</ReactFramework>

### HTML `<meta>` tag

For markup-only setups (CMS templates, server-rendered pages) where calling
`initialize` or wrapping in `DsRootProvider` isn't practical, a subset of the config can
instead be declared on a `<meta name="design-system-config">` tag in
`<head>`. This is read before any framework code runs, so it's also useful
to avoid a flash of default config (wrong region/language) while the app
boots.

<Code language="html" code={`
<meta
${' '}name="design-system-config"
${' '}data-brand="helvetia"
${' '}data-region="CH"
${' '}data-language="de"
${' '}data-allowed-languages="de,fr,it,en"
/>
`} />

Only `brand`, `region`, `language`, `fallbackLanguage`, `allowedLanguages`
(comma-separated), and `animated` (`"false"` or anything else, treated as
a boolean) are read from the tag. Everything else — icons, `legalLinks`,
`legalText`, `socialLinks` — is JS-only config.

<InfoQuote>
  Precedence, lowest to highest: default config → `<meta>` tag → the
  config passed to `initialize` or `DsRootProvider`, which always
  wins.
</InfoQuote>

## Change

{/* ################################################## */}
{/* -------------------------------------------------- */}
{/* Angular  ----------------------------------------- */}
{/* -------------------------------------------------- */}
{/* ################################################## */}

<AngularFramework>

To change the language or region during run time use the two functions `updateDsLanguage` and `updateDsRegion`.

<Code language="typescript" code={`
import { Component } from '@angular/core'
import { updateDsLanguage, DsSwissLanguage } from '@helvetia-design/core'

@Component({
${' '}selector: 'app-tab-a',
${' '}templateUrl: './app-tab-a.html',
})
export class AppTabA {
${' '}changeLang(lang: DsSwissLanguage) {
${' '}${' '}updateDsLanguage(lang)
${' '}}
}
`} />

</AngularFramework>

<ReactFramework>

To change the language or region at runtime, update the props on `DsRootProvider` from React state. Nested design system components pick up the new values automatically.

<Code language="tsx" code={`
import { useState } from 'react'
import { DsRootProvider, DsAppFooter } from '@helvetia-design/react'
import type { DsLanguage } from '@helvetia-design/core'

function App() {
${' '}const [language, setLanguage] = useState<DsLanguage>('de')

${' '}return (
${' '}${' '}<DsRootProvider
${' '}${' '}${' '}region="CH"
${' '}${' '}${' '}language={language}
${' '}${' '}${' '}allowedLanguages={['de', 'fr', 'it', 'en']}
${' '}${' '}>
${' '}${' '}${' '}<DsAppFooter onDsLanguageChange={event => setLanguage(event.detail.language as DsLanguage)} />
${' '}${' '}</DsRootProvider>
${' '})
}
`} />

</ReactFramework>

<HTMLFramework>

To change the language or region during run time use the two functions `updateDsLanguage` and `updateDsRegion`.

<Code language="typescript" code={`
import {
  updateDsAllowedLanguages,
  updateDsLanguage,
  updateDsRegion,
} from '@helvetia-design/core'

updateDsLanguage('de')
updateDsRegion('CH')
updateDsAllowedLanguages(['fr', 'it'])
`} />

The config can be accessed with `useConfig`. Both variants have the same effect.

<Code language="typescript" code={`
import { useConfig } from '@helvetia-design/core'

const config = useConfig()
config.language = 'de'
config.region = 'CH'
config.allowedLanguages = ['de', 'fr', 'it', 'en']
`} />

</HTMLFramework>

## Subscribe

{/* ################################################## */}
{/* -------------------------------------------------- */}
{/* Angular  ----------------------------------------- */}
{/* -------------------------------------------------- */}
{/* ################################################## */}

<AngularFramework>

To subscribe to changes of the region or language during runtime you can register your callback function using `onDsConfigChange`.

<Code language="typescript" code={`
import { Component, OnInit } from '@angular/core'
import { onDsConfigChange, DsConfigState } from '@helvetia-design/core'

@Component({
${' '}selector: 'app-sample',
${' '}templateUrl: './sample.html',
})
export class Sample implements OnInit {
${' '}constructor(private yourLangService: YourLangService) {}

${' '}ngOnInit(): void {
${' '}${' '}// IMPORTANT: register your config update callback in ngOnInit instead of the constructor
${' '}${' '}onDsConfigChange((config: DsConfigState) => {
${' '}${' '}${' '}// when the language is changed, e.g. in the footer, you probably want to update it in your translations service
${' '}${' '}${' '}this.yourLangService.changeLanguage(config.language)
${' '}${' '}})
${' '}}
}
`} />

</AngularFramework>

<ReactFramework>

To subscribe to changes of the region or language during runtime, listen to the corresponding event on `DsRootProvider` instead of calling `onDsConfigChange` directly.

<Code language="tsx" code={`
import { useState } from 'react'
import { DsRootProvider } from '@helvetia-design/react'
import type { DsLanguage } from '@helvetia-design/core'

function App() {
${' '}const [language, setLanguage] = useState<DsLanguage>()

${' '}return (
${' '}${' '}<DsRootProvider
${' '}${' '}${' '}region="CH"
${' '}${' '}${' '}language="de"
${' '}${' '}${' '}onDsLanguageChange={event => {
${' '}${' '}${' '}${' '}// when the language is changed, e.g. in the footer, you probably want to update it in your translations service
${' '}${' '}${' '}${' '}setLanguage(event.detail.language as DsLanguage)
${' '}${' '}${' '}}}
${' '}${' '}>
${' '}${' '}${' '}{/* Your application */}
${' '}${' '}</DsRootProvider>
${' '})
}
`} />

</ReactFramework>

<HTMLFramework>

To subscribe to changes of the region or language during runtime you can register your callback function using `onDsConfigChange`.

<Code language="typescript" code={`
import { onDsConfigChange, DsConfigState } from '@helvetia-design/core'

onDsConfigChange((config: DsConfigState) => {
// do something with the updated config here
})
`} />

</HTMLFramework>
