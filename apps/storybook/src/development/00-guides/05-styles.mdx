## Installation

To use the Helvetia Design System styles in your project, first install the
`@baloise/ds-css` package via npm or pnpm:

```bash
npm install @baloise/ds-css
# or
pnpm add @baloise/ds-css
```

## Import

`@baloise/ds-css` is built from the same [Design Tokens](?path=/docs/tokens-all-tokens--documentation)
that drive the rest of the system, and ships as three pieces you import separately — only **Base**
is required:

### Base

Design tokens as CSS variables, a CSS reset, and structural styles. Always required.

<Tabs
  tabs={[
    {
      label: 'CSS',
      content: (
        <Code
          language="css"
          code={`
@import '@baloise/ds-css/css/base.css';
`}
        />
      ),
    },
    {
      label: 'Sass',
      content: (
        <Code
          language="css"
          code={`
@use '@baloise/ds-css/scss/base';
`}
        />
      ),
    },
  ]}
/>

### Components

CSS-only classes (`.ds-button`, `.ds-heading`, ...) for using components as plain HTML instead of
the web components (`<ds-button>`, which load their styles automatically). Optional.

<Tabs
  tabs={[
    {
      label: 'CSS',
      content: (
        <Code
          language="css"
          code={`
@import '@baloise/ds-css/css/components.css';
`}
        />
      ),
    },
  ]}
/>

### Utilities

Helper classes for spacing, layout, typography, color, and more. Optional.

<Tabs
  tabs={[
    {
      label: 'CSS',
      content: (
        <Code
          language="css"
          code={`
@import '@baloise/ds-css/css/utilities.css';
`}
        />
      ),
    },
  ]}
/>

<InfoQuote>
  Components and Utilities only ship as compiled CSS (no per-component or per-utility-category
  files) — `@baloise/ds-css/scss/mixins` is still available separately if you just need the Sass
  breakpoint mixins without any styles.
</InfoQuote>

## Themes

Themes are the Design System's multi-brand solution — a theme applies one brand's tokens (e.g.
ERV, TCS) on top of the base styles. See [Theming](?path=/docs/development-theming--documentation)
for how to activate a predefined theme, customize individual components, and request a new brand.
