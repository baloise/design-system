## Installation

To use the Helvetia Design System styles in your project, install `@baloise/ds-styles` and
`@baloise/ds-tokens` via npm or pnpm:

```bash
npm install @baloise/ds-styles @baloise/ds-tokens
# or
pnpm add @baloise/ds-styles @baloise/ds-tokens
```

## Import

Global styles come from two packages you import separately — only **Tokens** and
**Foundation + Components** are required. `@baloise/ds-styles` no longer ships token values itself,
only `var(--ds-*)` references, so Tokens must be loaded before Foundation + Components for
anything to render correctly.

### Tokens

Every `--ds-*` CSS custom property. Always required, load first.

<Tabs
  tabs={[
    {
      label: 'CSS',
      content: (
        <Code
          language="css"
          code={`
@import '@baloise/ds-tokens/css/base';
`}
        />
      ),
    },
  ]}
/>

<InfoQuote>
Using a different brand? Import `@baloise/ds-tokens/css/erv` or `@baloise/ds-tokens/css/tcs`
instead of `@baloise/ds-tokens/css/base` — each is a complete, standalone token set. See
**Development/Theming**.
</InfoQuote>

### Foundation + Components

CSS reset, structural styles, and CSS-only classes (`.ds-button`, `.ds-heading`, ...) for using
components as plain HTML instead of the web components (which load their own styles
automatically). Ship together as one pre-built bundle. Always required.

<Tabs
  tabs={[
    {
      label: 'CSS',
      content: (
        <Code
          language="css"
          code={`
@import '@baloise/ds-styles/css/design-system';
`}
        />
      ),
    },
  ]}
/>

### Utilities

Helper classes for spacing, layout, typography, color, and more. Optional.

<Tabs
  tabs={[
    {
      label: 'CSS',
      content: (
        <Code
          language="css"
          code={`
@import '@baloise/ds-styles/css/utilities';
`}
        />
      ),
    },
  ]}
/>

<InfoQuote>
  Components and Utilities only ship as compiled CSS (no per-component or per-utility-category
  files) — `@baloise/ds-styles/scss/mixins` is still available separately if you just need the Sass
  breakpoint mixins without any styles.
</InfoQuote>

## Themes

Themes are the Design System's multi-brand solution — a theme applies one brand's tokens (e.g.
ERV, TCS) on top of the base styles. See [Theming](?path=/docs/development-theming--documentation)
for how to activate a predefined theme, customize individual components, and request a new brand.
