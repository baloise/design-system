## CSS Variables

Every value in the Design System — colors, spacing, typography, and each component's own styling —
is exposed as a [CSS Variable](https://developer.mozilla.org/en-US/docs/Web/CSS/Using_CSS_custom_properties).


A CSS Variable is defined once and referenced everywhere, so overriding it in one place cascades
everywhere it's used — no build step or preprocessor required.

## Customize Components

### Globally

Override a design token in `:root` and every component using it picks up the new value.

<Code
  language="css"
  code={`
:root {
  --ds-global-color-primary: pink;
  --ds-global-font-family-heading: 'Roboto', sans-serif;
}
`}
/>

### By Component

Every component also exposes its own public variables. Target its selector to override just that
component, everywhere it appears:

<Code
  language="css"
  code={`
ds-badge {
  --ds-badge-background: aqua;
}
`}
/>

<br />

Or scope it to a single instance with a class:

<br />

<Code
  language="css"
  code={`
.my-badge {
  --ds-badge-background: lime;
}
`}
/>

<InfoQuote>
  See [Component Variables](?path=/docs/tokens-component-variables--documentation) for the full
  private/public/modifier/token variable cascade each component follows.
</InfoQuote>

## Predefined Brand Themes

A **theme** applies one brand's token overrides — colors, typography, and more — on top of the
base styles, scoped under a `[data-theme="<brand>"]` selector (e.g. ERV, TCS). To activate one:

<br />

**1. Import the theme's tokens**

Import the brand's compiled token stylesheet after `@baloise/ds-css/css/base.css` (see
[Styles](?path=/docs/development-styles--documentation)) so its overrides win the cascade.

<br />

<Code
  language="css"
  code={`
@import '@baloise/ds-tokens/css/tcs.tokens.css';
`}
/>

<br />
<br />

**2. Activate the theme**

Set `data-theme="<brand>"` on your root element.

<br />

<Code
  language="html"
  noPreview
  code={`
<html data-theme="tcs">
`}
/>

<InfoQuote>
  Brand themes are actively being built out and aren't all published yet — check with the Design
  System team for which brands are currently available to consume, and under which package path.
</InfoQuote>

### Requesting a New Brand

Need a brand that isn't available yet? Open a
[Theme Report](https://github.com/baloise/design-system/issues/new?template=theme_report.yml) —
include a link to the brand's guidelines (colors, typography, logo) if you have one, so the
Design System team can scope the token overrides.
