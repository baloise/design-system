## Choose an overlay

- **Modal** — interrupt the user for a decision, confirmation, or focused workflow.
- **Toast** — briefly confirm a completed action and dismiss automatically.
- **Snackbar** — keep important information visible until the user dismisses it.

## HTML and JavaScript

### Modal

Render the modal in the document and call its `present()` and `dismiss()` methods.

```html
<ds-button onclick="document.getElementById('modal-basic').present()">Open modal</ds-button>

<ds-modal id="modal-basic">
  <ds-modal-header>Confirm action</ds-modal-header>
  <ds-modal-body>
    <p>Do you want to continue?</p>
  </ds-modal-body>
  <ds-button slot="actions" onclick="document.getElementById('modal-basic').dismiss()">
    Cancel
  </ds-button>
</ds-modal>
```

### Toast and snackbar

Use the controllers from `@baloise/ds-core` to create and remove notifications. `create()` returns the ID needed by
`remove()`.

```ts
import { dsSnackbarController, dsToastController } from '@baloise/ds-core'

const toastId = await dsToastController.create({
  heading: 'Saved',
  message: 'Your changes have been saved.',
  closable: true,
  duration: 5000,
  closeHandler: () => undefined,
  actionHandler: () => undefined,
})

if (toastId) {
  await dsToastController.remove(toastId)
}

const snackbarId = await dsSnackbarController.create({
  heading: 'Offline',
  message: 'You are currently offline.',
  closable: true,
  duration: 'infinite',
  closeHandler: () => undefined,
  actionHandler: () => undefined,
})

if (snackbarId) {
  await dsSnackbarController.remove(snackbarId)
}
```
