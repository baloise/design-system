## Next.js App Router

`@baloise/ds-react` supports server-side rendering with the Next.js App Router. Plain `Ds*` components render
Declarative Shadow DOM on the server. The browser turns that markup into shadow roots and then upgrades the elements
to make them interactive.

Use the same `@baloise/ds-react` import in Server and Client Components. The package automatically selects its server
entry in Node.js and its client entry in the browser.

## Installation

Install the React bindings, core package, global styles, and design tokens:

```bash
npm add -E @baloise/ds-react @baloise/ds-core @baloise/ds-styles @baloise/ds-tokens
# or
pnpm add -E @baloise/ds-react @baloise/ds-core @baloise/ds-styles @baloise/ds-tokens
```

The core package is required so Next.js can keep it external in the server build.

## Configure Next.js

Keep `@baloise/ds-core` external in the Next.js server build.

**next.config.ts**

```ts
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  serverExternalPackages: ['@baloise/ds-core'],
}

export default nextConfig
```

<InfoQuote>
  In a monorepo, you may also need to point Turbopack at the workspace root:

  ```ts
  import path from 'node:path'

  const nextConfig: NextConfig = {
    turbopack: {
      root: path.join(__dirname, '..', '..'),
    },
    serverExternalPackages: ['@baloise/ds-core'],
  }
  ```
</InfoQuote>

## Render components on the server

A page without browser state or event handlers can remain a Server Component. No `'use client'` directive is needed.

**app/page.tsx**

```tsx
import { DsButton, DsCheckbox, DsInput } from '@baloise/ds-react'

export default function HomePage() {
  return (
    <main>
      <h1>My server-rendered page</h1>
      <DsButton>Continue</DsButton>
      <DsInput name="first-name" label="First name" />
      <DsCheckbox>I accept the terms</DsCheckbox>
    </main>
  )
}
```

## Verify server rendering

Test server rendering with a production build:

```bash
next build
next start
```

Open the page source and look for `shadowrootmode` inside a rendered `ds-*` element. This confirms that the server
response contains Declarative Shadow DOM before JavaScript runs. Do not use `next dev` to verify the production SSR
output.
