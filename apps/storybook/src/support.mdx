## Supported Frameworks

Our components are built as native Web Components, so they work anywhere HTML runs. We officially recommend and
maintain integrations for **React**, **Angular**, and **vanilla HTML** — these are the technologies our team develops
against directly, and every release is verified with visual and functional tests to catch regressions before they
reach you.

- Label, close, and manage GitHub issues
- Close and merge GitHub pull requests
