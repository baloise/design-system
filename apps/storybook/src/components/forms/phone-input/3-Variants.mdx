<StoryHeading of={PhoneInputStories.Invalid}></StoryHeading>

An invalid field shows validation styling and `invalidText`. The component does not decide whether a number is valid — the application sets this state.

<StoryHeading of={PhoneInputStories.InvalidTextSlot}></StoryHeading>

<CanvasWithCodePen of={PhoneInputStories.InvalidTextSlot} sourceState="shown" overflowVisible={true} />

<StoryHeading of={PhoneInputStories.WithDescription}></StoryHeading>

<CanvasWithCodePen of={PhoneInputStories.WithDescription} sourceState="shown" overflowVisible={true} />

<StoryHeading of={PhoneInputStories.Disabled}></StoryHeading>

`disabled` blocks both the country picker and the number field.

<CanvasWithCodePen of={PhoneInputStories.Disabled} sourceState="shown" overflowVisible={true} />

{/* ------------------------------------------------------ */}

<StoryHeading of={PhoneInputStories.Readonly}></StoryHeading>

`readonly` disables the country picker but leaves the national number focusable and selectable.

<CanvasWithCodePen of={PhoneInputStories.Readonly} sourceState="shown" overflowVisible={true} />

{/* ------------------------------------------------------ */}

<StoryHeading of={PhoneInputStories.FormattedValue}></StoryHeading>

Pass the canonical E.164 `value`. The field displays the country's international grouping without the calling code,
because that code is already visible in the country trigger.

<CanvasWithCodePen of={PhoneInputStories.FormattedValue} sourceState="shown" overflowVisible={true} />

{/* ------------------------------------------------------ */}

<StoryHeading of={PhoneInputStories.Formatting}></StoryHeading>

Each country uses its own international grouping without repeating the calling code. Formatting is applied while
typing. On blur, a national trunk prefix such as the Swiss `0` is removed, while significant leading digits such as an
Italian landline's `0` remain.
