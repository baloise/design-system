## When to Use

- Illustrate product categories or insurance lines (e.g. car, home, travel) in cards, tiles, or overviews
- Reinforce a section's topic with a large, colorful, decorative visual
- Pair with a tile background to create a compact category marker
- Show a disabled or invalid variant when the represented category is unavailable or has a data problem

## When NOT to Use

- As a functional, interactive UI icon — use `ds-icon` for actions, navigation, and status indicators
- As the only way to identify a category — always pair it with a text label
- At very small sizes where the illustration's detail is no longer legible
- To convey urgency or system status (error, warning, success) — brand icons are decorative, not semantic

## Do's and Don'ts

### Pair with a Text Label

Brand icons are decorative illustrations, not self-explanatory symbols. Always accompany them with a label that names the category.

### Use the Right Icon for the Job

Brand icons are large, illustrative, and decorative. For compact functional icons in buttons, links, or status messages, use `ds-icon` instead.
