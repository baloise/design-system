## Guidelines

<A11yGuidelines
  items={[
    {
      type: 'do',
      title: 'Pair with a Visible Label',
      content: (
        <p style={{ margin: '0.5rem 0 0 0' }}>
          The icon renders with <code>aria-hidden="true"</code> and is not announced to screen readers. Always place a
          visible text label next to it so the represented category is available to everyone.
        </p>
      ),
    },
    {
      type: 'do',
      title: 'Use Sufficient Color Contrast',
      content: (
        <p style={{ margin: '0.5rem 0 0 0' }}>
          When using the <code>tile</code> background, verify the icon's fill colors keep enough contrast against the
          tile background, especially in the <code>disabled</code> and <code>invalid</code> states.
        </p>
      ),
    },
    {
      type: 'do',
      title: 'Keep a Legible Size',
      content: (
        <p style={{ margin: '0.5rem 0 0 0' }}>
          Use a size large enough that the illustration's details remain distinguishable, particularly for users with
          low vision.
        </p>
      ),
    },
    {
      type: 'dont',
      title: 'Rely on the Icon Alone',
      content: (
        <p style={{ margin: '0.5rem 0 0 0' }}>
          Do not use the icon as the only way to identify a category or product. Screen reader users and users who
          don't recognize the illustration need a text alternative.
        </p>
      ),
    },
    {
      type: 'dont',
      title: 'Use Color as the Only State Indicator',
      content: (
        <p style={{ margin: '0.5rem 0 0 0' }}>
          Don't rely solely on the <code>invalid</code> or <code>disabled</code> color change to communicate state —
          pair it with a text label or surrounding context.
        </p>
      ),
    },
  ]}
/>
