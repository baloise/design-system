## Legal Links, Social Links & Legal Text

`legalLinks` and `socialLinks` are not props on `ds-app-footer` — they live in the global config, keyed by
`region` (and, for `legalLinks`/`legalText`, also `language`), so every footer instance on the page renders the
same defaults for the active region/language. `legalText` can additionally be overridden per instance with a prop.

<AngularFramework>

Set the defaults once in `provideDesignSystem()`, in `app.config.ts`.

<Code language="typescript" code={`

import { provideDesignSystem } from '@baloise/ds-angular'

export const appConfig: ApplicationConfig = {
${' '}providers: [
${' '}${' '}provideDesignSystem({
${' '}${' '}${' '}defaults: {
${' '}${' '}${' '}${' '}legalLinks: {
${' '}${' '}${' '}${' '}${' '}CH: {
${' '}${' '}${' '}${' '}${' '}${' '}de: [
${' '}${' '}${' '}${' '}${' '}${' '}${' '}{ label: 'Impressum', href: 'https://example.com/impressum' },
${' '}${' '}${' '}${' '}${' '}${' '}${' '}{ label: 'Datenschutz', href: 'https://example.com/datenschutz' },
${' '}${' '}${' '}${' '}${' '}${' '}],
${' '}${' '}${' '}${' '}${' '}},
${' '}${' '}${' '}${' '}},
${' '}${' '}${' '}${' '}legalText: {
${' '}${' '}${' '}${' '}${' '}CH: { de: '© 2026 Your Company · Musterstrasse 1 · CH-4000 Basel' },
${' '}${' '}${' '}${' '}},
${' '}${' '}${' '}${' '}socialLinks: {
${' '}${' '}${' '}${' '}${' '}CH: [{ label: 'LinkedIn', href: 'https://linkedin.com/company/example', icon: 'linkedin' }],
${' '}${' '}${' '}${' '}},
${' '}${' '}${' '}},
${' '}${' '}}),
${' '}],
}
`} />

```html

```

</AngularFramework>

<ReactFramework>

${' '}${' '}${' '}legalLinks={{

${' '}${' '}${' '}${' '}${' '}${' '}{ label: 'Impressum', href: 'https://example.com/impressum' },
${' '}${' '}${' '}${' '}${' '}${' '}{ label: 'Datenschutz', href: 'https://example.com/datenschutz' },
${' '}${' '}${' '}${' '}${' '}],
${' '}${' '}${' '}${' '}},
${' '}${' '}${' '}}}
${' '}${' '}${' '}legalText={{ CH: { de: '© 2026 Your Company · Musterstrasse 1 · CH-4000 Basel' } }}

<InfoQuote>
  Need fully custom markup instead of the config-driven defaults? Set `disableDefaultLinks` /
  `disableDefaultSocialLinks` and provide your own content via the `links` / `social-links` slots.
</InfoQuote>

## When to Use

- Display application-level legal links, copyright information, and contact details
- Provide language selection for multilingual applications
- Include social media links and branding
- Present navigation options for privacy policies and imprints

## When NOT to Use

- For inline content that doesn't belong at the page bottom
- As a replacement for main navigation (use header components instead)
- For temporary or contextual information (use alerts or modals)
