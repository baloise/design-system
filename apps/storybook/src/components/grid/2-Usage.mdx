## When to Use

- Arranging content into rows and columns for page layouts, forms, or card groups.
- Building responsive layouts where column widths need to change per breakpoint.
- Laying out a fixed number of items that should share available width equally or in fixed proportions.

## When NOT to Use

- For form field layout specifically — use the `ds-form` grid, which already wraps this behaviour.
- For single-item width constraints on a page — use `ds-container` instead.
- For lists of unknown length that should wrap into a card grid with fixed-size tiles — a plain CSS grid may be simpler than the 12-column flex model.
