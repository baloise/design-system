<StoryHeading of={GridStories.ColumnSizes}></StoryHeading>

Use `is-*` fraction classes (`is-half`, `is-one-third`, `is-two-thirds`, `is-one-quarter`, `is-three-quarters`) or numeric classes (`is-1` through `is-12`) on a `ds-col` to set a fixed width; columns without a size class share the remaining space equally.

<StoryHeading of={GridStories.Gapless}></StoryHeading>
