## When to Use

- Display persistent notifications that remain visible until the user dismisses them
- Show feedback for user actions that have completed successfully or with warnings
- Provide important information that users should be able to review at their own pace
- Display multiple notifications stacked on top of each other

## When NOT to Use

- For time-sensitive notifications that disappear automatically — use **Toast** instead
- For critical errors that require immediate user attention — use **Alert** in a modal dialog
- For inline validation feedback on form fields — use field-level error messages

## Present and dismiss a snackbar

`useSnackbar()` returns `present` and `dismiss` functions. Use a snackbar when the message should remain available until
it is dismissed.

<InfoQuote>
  Import `useSnackbar` from `@baloise/ds-react`. The generated `DsSnackbar` wrapper is not a public export.
</InfoQuote>

```tsx
import { DsButton, useSnackbar } from '@baloise/ds-react'

export function SnackbarExample() {
  const [presentSnackbar, dismissSnackbar] = useSnackbar()

  const showSnackbar = () =>
    presentSnackbar({
      heading: 'Offline',
      message: 'You are currently offline.',
      closable: true,
      duration: 'infinite',
      closeHandler: () => undefined,
      actionHandler: () => undefined,
    })

  return (
    <>
      <DsButton onDsClick={showSnackbar}>Show snackbar</DsButton>
      <DsButton onDsClick={() => dismissSnackbar()}>Dismiss snackbar</DsButton>
    </>
  )
}
```
