## When to Use

- Adjusting a small, bounded integer or decimal value one step at a time (quantity, count, percentage)
- When the exact current value matters and should always be visible
- For inputs where overshooting by one step is recoverable and expected (e.g. adding items to a cart)

## When NOT to Use

- When the range is large (e.g. 0–1000) — repeated clicking becomes tedious; use `ds-number-input` instead
- For free-form numeric entry where the user knows the exact value — use `ds-number-input`
- For continuous ranges where dragging is more natural — use `ds-input-slider`
